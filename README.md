# Hola, soy Ricardo Román 👋

Me interesan el **vídeo, el streaming en tiempo real y los sistemas multimedia**, y también el hardware conectado y la visión artificial.

- 🔐 Seguridad de contenidos: DRM, AES, RSA y firma digital
- 📡 Sistemas embebidos con **ESP32** y **M5Stack** que envían datos en tiempo real
- 👁️ Visión artificial con **YOLOv8** y **OpenCV**
